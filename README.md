
Projeto educativo de uma loja virtual criado com **HTML, CSS e JavaScript**.


## Recursos

- Vitrine responsiva de produtos;
- Sacola de compras com contador interativo;
- Menu adaptado para telas menores;
- Link para download do [Eclipse IDE](https://www.eclipse.org/downloads/).

## Como executar

Abra o arquivo `index.html` diretamente no navegador ou use a extensão **Live Server** no seu editor.
